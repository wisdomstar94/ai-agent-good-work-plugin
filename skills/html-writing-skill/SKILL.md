## 규격

- **CSS · JS 를 포함한 HTML 파일 하나**로 출력합니다. 섹션 제목과 목차를 포함한 **하나의 긴 페이지**로 구성합니다. 최상위 구조에 탭을 쓰지 마세요. 휴대폰에서도 보이게 기본 반응형 스타일을 넣습니다.
- 저장한 뒤 **그 산출물을 언급할 때마다 워크스페이스 루트 기준으로, 파일명까지 포함한 상대경로**를 적습니다.
- 글은 **Martin Kleppmann 처럼 명료하고 유려한 문체**로 씁니다. 섹션 간 전환이 자연스러워야 합니다.
- 핵심 개념 · 정의 · 중요한 예외는 **콜아웃으로 강조**합니다.

## 다이어그램 · 목록 · 코드블록

**소수의 다이어그램 유형을 골라 문서 전체에서 재사용**하세요. 유용한 유형은 다음 두 가지입니다.

- 사용자가 앱에서 보는 **UI 를 매우 단순화한 그림** — UI 변경 설명용
- 시스템 구성 요소 간 **데이터 흐름 / 통신 다이어그램** — **예시 데이터를 반드시 포함**

다이어그램 · 목록 · 코드블록은 아래 규칙을 따릅니다.

- **ASCII 다이어그램을 쓰지 마세요.** 다이어그램은 HTML · CSS 로 간단히 그리고, 목록은 HTML 리스트로 만듭니다.
- 코드블록은 **`<pre>` 태그**를 쓰세요. 커스텀 div 를 쓴다면 CSS 에 **`white-space: pre-wrap` 이 반드시** 있어야 합니다. 없으면 줄바꿈이 무시되어 코드가 한 줄로 이어집니다. **저장 전에 각 코드블록이 `<pre>` 태그이거나, CSS 에 `white-space: pre-wrap` 이 있는지 확인하세요.**
