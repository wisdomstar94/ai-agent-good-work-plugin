## 사용자의 선택이 필요하면 항상 질문 프롬프트를 사용하세요

승인을 받거나 질문을 할 때는 문서나 터미널(채팅)에 질문과 선택지를 적어 두는 것으로 끝내지 마세요. 각 에이전트에 내장된 질문 프롬프트 기능으로 질문과 여러 선택지를 제공해, 사용자가 방향키로 선택지를 고르고 확정할 수 있게 해야 합니다.

## 선택지에는 추천 선택지를 포함해 여러 안을 제시하세요

- 질문 프롬프트로 결정을 받을 때는 추천 선택지를 포함하여 여러 선택지를 제공하세요. 아래는 그 예시입니다.

  ```text
  1. [Q3-1] 버튼 컴포넌트에 a 라는 신규 prop 을 추가한다. (추천 : {추천 이유 설명})
  2. [Q3-2] 여러 버튼 컴포넌트를 인자로 받아 새로운 버튼 컴포넌트를 반환하는 고차 컴포넌트를 새로 만든다.
  3. [Q3-3] a 라는 기능을 포함한 A_버튼 컴포넌트를 새로 만든다.
  ```

  `[Q3-1]` 은 `[질문 번호-선택지 번호]` 를 뜻합니다. 이 번호 표기는 유지하되, 위 선택지 내용은 예시일 뿐이니 선택지는 상황에 맞게 작성하세요.

- 추천 선택지에는 추천 이유를 함께 적으세요.
- `직접 입력` 같은 자유 입력용 선택지는 넣지 마세요. 에이전트의 질문 프롬프트가 자유 입력칸을 자체 제공하므로, 그 라벨을 고르면 내용 없는 답만 돌아옵니다.
