**주석은 최대한 지양합니다.** 꼭 남겨야 한다면 **짧고 간결하고 명료하게** 씁니다.

코드가 바뀌었을 때 주석도 따라 바뀌지 않으면, **틀린 설명이 그대로 남아** 다음에 코드를 읽는 사람을 잘못된 전제로 끌고 갑니다.
없는 주석은 아무도 오해시키지 않지만, 낡은 주석은 반드시 누군가를 오해시킵니다.

## 코드만 보고 알 수 있는 내용은 주석으로 달지 마세요

코드만 봐도 알 수 있는 내용을 굳이 주석으로 작성하지 않습니다. 아래는 그 예시입니다.

## 로컬 PC에 종속된 내용을 주석에 포함하지 마세요

로컬 PC에 종속적인 내용(예. 레포 밖의 파일 또는 gitignore 에 의해 git 에 포함되지 않는 파일 등)을 주석에 포함하여 작성하지 마세요.
다른 팀원이 해당 레포에서 주석을 봤을 때, 혼란을 일으킬 수 있습니다.
